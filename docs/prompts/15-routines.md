# Presenter beat 15 — Routines

Requirement: a known L-417 discrepancy should receive a bounded read-only investigation without an
operator clicking Ask. Activation grants no new authority.

Use the optional Hosting walkthrough step and
[Routines and Insights runbook](../runbooks/routines-and-insights.md). The implemented increment is
a source-controlled timer manifest and explicit CLI create/show/dispatch/run/enable/disable script.
Creation is disabled by default. It targets the existing deployed read-only agent composition.

The cloud run history is authoritative for execution. Show actual output, principal, timestamps
and current Hub state. Work IQ delegation is not assumed for unattended invocations. Do not compose
remediation or direct device-write tools into the scheduled agent.

No runtime stage enum is added: this is an orthogonal activation demonstration, not a reason to
enable every later local capability. Hub-event activation, persistent admission/idempotency and a
local simulation adapter remain separate implementation tasks.
